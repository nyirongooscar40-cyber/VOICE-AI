# Bright Learn Voice AI Agent - Oscar

This repository contains the configuration, system prompts, tool schemas, and normalization rules for **Oscar**, the automated Voice AI Enrollment Advisor for the Bright Learn edtech platform. 

Oscar handles inbound voice calls, chat, and LMS-integrated audio channels to assist learners and parents with course routing, scheduling, payments, and trial bookings.

##  Quick Start
* **System Persona:** `Oscar` (Friendly, Encouraging, Professional Advisor)
* **Target Platform:** Inbound telephony, LMS WebRTC channels, and live chat
* **Core Tech Stack:** Voice AI orchestrator, Google Sheets API, LMS Knowledge Base
